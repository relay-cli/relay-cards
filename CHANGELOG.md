# Changelog

## 0.1.0

- Launch a child server command or read piped input.
- Recognize HTTP access logs, JSON, errors, warnings, process events, and text.
- Present events as an interactive card feed with filtering, navigation, expansion, and raw view.
- Bound event history and group repeated events.
- Preserve signals and exit status across the wrapper.
- Include a deterministic local demo and plain-output mode.
