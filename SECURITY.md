# Security

## Supported version

Security fixes are applied to the latest release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Include the affected version, operating system, reproduction steps, and the expected impact.

Please avoid opening a public issue until a fix or mitigation is available.

## Process execution

Relay Cards executes the command supplied by the user and inherits the current environment unless the embedding application provides a different one. Treat command arguments and environment variables with the same care as the server process itself.
