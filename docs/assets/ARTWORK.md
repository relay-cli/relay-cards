# Repository artwork

The banner and social preview were generated with the built-in image-generation tool using the official Relay mark as the visual reference.

## Banner direction

The README banner presents the Relay mark and product name beside three terminal cards: an HTTP request, a JSON record, and a stack trace. It uses the shared Relay palette and a wide 3:1 composition.

## Social-preview direction

The social preview recomposes the same approved artwork for a 2:1 frame. It removes the supporting sentence, enlarges the product name, and preserves the three-card interface at thumbnail size.

Future artwork should continue using the official mark stored in the Relay organization package. Repository visuals should depict the actual interface categories instead of decorative terminal code.
